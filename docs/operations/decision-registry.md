# Registre canonique des décisions externes — 21-P0

**Référence de version :** document vivant ; vérifier le commit courant du dépôt
avant utilisation. Les anciennes baselines `origin/main = ...` sont historiques.
**Dernière revue de cohérence :** 2026-08-30
**Statut :** `EXTERNAL_DECISION_READY = PASS`
**Portée :** préparation des décisions humaines nécessaires au premier pilote réel.

Ce registre ne vaut ni approbation juridique, ni validation comptable, ni décision
DPO, ni go produit. Il prépare les questions, les preuves et les prochaines
actions. Une décision n'est considérée comme prise qu'après une réponse humaine
écrite, datée, signée ou explicitement attribuée, puis référencée dans la
matrice de readiness.

Chaque décision ci-dessous possède un identifiant unique. Les identifiants sont
canoniques : un même choix n'est pas recopié sous un autre identifiant dans un
autre pack. Les packs spécialisés ne référencent que leur famille d'identifiants.

## Règle de clôture de 21-P0

`EXTERNAL_DECISION_READY = PASS` signifie uniquement que chaque question
externe est identifiée par un ID unique, possède un owner, une preuve technique,
les contraintes/valeurs actuelles, une action suivante et un chantier futur ou
`NONE`, et que les incertitudes sont actionnables. Cela ne signifie pas que les
humains ont approuvé les choix.

Les statuts finaux restent séparés :

- `TECHNICAL_READY` : reprend la preuve technique du Chantier 20, sans recalcul dans ce document ;
- `EXTERNAL_DECISION_READY` : `PASS`;
- `EXTERNAL_SIGNOFF_READY` : `BLOCKED`, aucune approbation humaine n'étant présente ici ;
- `PILOT_READY` : `BLOCKED`, tant que les décisions, configurations et validations opératoires ne sont pas closes.
